# Confidence Intervals

## Purpose
Score whether extracted evidence supports explicit diagnostic criteria.

## Project-specific implementation note
Use versioned external criteria, evidence provenance, missing/contradictory clues and physician adjudication; toy criteria are not medical rules.

## Required before clinical research
Specify protocol owner, clinical specialty, data provenance, eligibility, reference standard, independent review, statistical plan, and approvals where applicable.

## Current status
Not implemented or clinically validated; documentation template for future completion.
